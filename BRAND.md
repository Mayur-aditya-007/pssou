## 2. Typography

Universities in India maintain dignified, readable typography with strong Devanagari (Hindi) and English bilingual rendering.

- **Primary Headings (`h1`, `h2`, `h3`, `h4`)**: `'Raleway', 'Segoe UI', system-ui, sans-serif`
- **Body & Information Cards**: `'Roboto Condensed', 'Roboto', 'Noto Sans Devanagari', sans-serif`
- **Tables, Form Inputs, & Interactive Elements**: `'Inter', system-ui, -apple-system, sans-serif`

### Type Scale
- `Display / Hero Title`: 32px – 48px (Weight: 700 / 800)
- `Section Heading (h2)`: 24px – 30px (Weight: 700)
- `Subheading / Card Title (h3)`: 18px – 22px (Weight: 600)
- `Card Header / Field Label (h4)`: 15px – 16px (Weight: 600)
- `Body Text (p, inputs)`: 14px – 15px (Weight: 400 / 500, Line Height: 1.55)
- `Captions & Badges`: 12px – 13px (Weight: 600 / 700, Uppercase tracking)

## 4. UI Geometry, Spacing & Shadows

- **Border Radii**:
  - Small pills & badges: `20px` (`rounded-full`)
  - Modern cards: `12px` – `16px` (`rounded-xl` / `rounded-2xl`)
  - Date blocks / button inputs: `8px` (`rounded-lg`)
  - Split date badges: `border-radius: 7px 0 0 7px` (left) & `0 7px 7px 0` (right)
- **Shadows**:
  - Card baseline: `0 4px 20px rgba(0, 0, 0, 0.05)`
  - Card hover: `0 15px 30px rgba(0, 0, 0, 0.1)`
  - Header sticky shadow: `0 8px 30px rgba(0, 0, 0, 0.12)`
- **Header Structure**:
  - Height: `70px` (desktop), `54px` (mobile)
  - Background: `#1a5f7a` with `border-bottom: 3px solid #159895`
